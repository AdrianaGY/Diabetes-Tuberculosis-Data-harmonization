# Diabetes and Tuberculosis: Harmonization of Population-Based Datasets
This repository contains the code and documentation used to harmonize data from:
- CARDIA
- HCHS/SOL
- NHANES

## Manuscript
Preprint available at:
https://doi.org/10.21203/rs.3.rs-11311043/v1

## Contents
- cardia.Rmd
- hchs_sol.Rmd
- nhanes.Rmd
- merged_data.Rmd
- User Guide.pdf
- Variable Mapping.xlsx

## Data availability
Original datasets cannot be redistributed due to data-use agreements.
Researchers must obtain access directly through BioLINCC, NHANES, and the All of Us Research Program.
